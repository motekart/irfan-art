FOLDER IKON HEWAN UNTUK PETA
=============================
Taruh ikon hewan buatan Anda di folder ini. Nama file mengikuti daftar di bawah
(format .svg lebih disarankan; .png juga dikenali). Ikon yang belum ada otomatis
tampil sebagai placeholder jejak kaki, jadi Anda bisa menggantinya satu per satu.

Ukuran saran: persegi (mis. 256x256 px), latar transparan.

SUMATERA     : orangutan-tapanuli, harimau-sumatera, gajah-sumatera, badak-sumatera
KALIMANTAN   : orangutan-kalimantan, bekantan, enggang-gading, beruang-madu
JAWA         : owa-jawa, elang-jawa, kukang-jawa, badak-jawa, macan-tutul-jawa
SULAWESI     : anoa, tarsius, babirusa, maleo
MALUKU       : kakatua-maluku, bidadari-halmahera, kasturi-ternate
NUSA TENGGARA: komodo, jalak-bali, kakatua-jambul-kuning
PAPUA        : kasuari, cenderawasih, kanguru-pohon

Contoh: assets/icons/owa-jawa.svg

Mengubah daftar hewan per pulau: buka assets/main.js, cari "var REG=" dan edit
bagian "a:[...]" pada pulau yang diinginkan.
